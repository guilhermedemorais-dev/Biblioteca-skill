# Site Delivery Standard

Use SEO Standard primarily for landing pages, institutional websites, service
pages and small ecommerce projects.

## Core delivery gate

A site should not be considered SEO-ready until applicable checks cover:

- crawlability and indexability;
- robots, sitemap, canonical and redirects;
- title, meta description and heading structure;
- semantic HTML and page intent;
- structured data/schema grounded in real business facts;
- internal links and navigation;
- mobile behavior and performance evidence when available;
- AEO/GEO answer structure and entity clarity;
- conversion copy and CTA clarity;
- post-change revalidation.

## Conversion copy

SEO copy and conversion copy are separate concerns and both matter.

For commercial pages, inspect:

- headline and primary promise;
- audience/problem fit;
- benefits versus feature dumping;
- objections and trust proof;
- CTA wording and hierarchy;
- FAQ usefulness;
- message consistency from query intent to page action.

Do not invent scarcity, testimonials, guarantees, rankings or business claims.

## Workflow

```text
website/project
  -> seo-standard audit
  -> evidence-backed findings
  -> sdd-spec-factory / existing Task
  -> dev-implementation-standard
  -> seo-standard revalidation
  -> qa-testing-standard + ui-ux-standard when applicable
  -> delivery gate
```

The SEO specialist may propose exact copy and metadata, but product code changes
remain owned by dev-implementation-standard.
