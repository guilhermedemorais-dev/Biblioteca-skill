# Biblioteca do TFD

Abra o [índice de recursos](indexes/resources.json)
para localizar referências e artefatos por ID, título, categoria ou palavras-chave.
O campo `path` de cada entrada é relativo a esta pasta `library/`.

- [Modelos de artefatos](templates/)
- [Inventário de reconstrução](reconstruction/inventory-template.md)
- [Modelos de documentação](documentation-templates/README.md)

Os recursos indexados são referências para consulta. O índice
`indexes/skill-routes.json` guarda o roteamento histórico para consulta e os
agentes ativos do TFD ficam na pasta `agents/` na raiz do plugin.
Links históricos para ferramentas e agentes descrevem o ambiente de origem.

A biblioteca é a primeira fonte do Discovery. Abra apenas os recursos selecionados
no índice e confira se a origem e a revisão servem ao caso. Registre no projeto o
recurso usado, sua revisão e a seção consultada.

Se o índice estiver inacessível, informe o caminho que falhou.
Se o índice estiver acessível mas os recursos não
responderem à pergunta, informe a lacuna. Quando o usuário pedir pesquisa adicional,
use Context7 como primeira opção para documentação técnica e registre a fonte
validada no `docs/` do projeto.
