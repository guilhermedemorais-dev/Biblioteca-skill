## Use and limits

Treat entries as leads. Verify the provider's official documentation, endpoint
and version, authentication, current pricing and quotas, terms, data handling,
and suitability for the actual requirement. APIs intended for government-to-
government use may not be available to general developers. Prefer mocks or
synthetic data for validation. Do not bulk copy the catalog into a project spec
or send customer data during discovery.
