# API discovery: `public-apis/public-apis`

Use this community-maintained directory to discover candidate public APIs when
a project requirement actually needs an external API. It supplements the
inherited API Research Library; it is a discovery pointer, not an approved
dependency list, an API runtime, or an MCP catalog. Do not mirror its entries
into project specs or install/connect services during discovery.

## Use and limits

The README describes the directory as manually curated by community members
and APILayer contributors and includes APILayer promotional material. Treat
listings as leads. A listing does not establish that a service is currently
available, free, unlimited, suitable for commercial use, or safe for a given
data flow. The repository license does not replace each provider's service
terms or license.

Before recommending a candidate, verify its official provider documentation,
authentication, current pricing and quotas, data handling, license and terms.
Prefer mocks or local tests when they meet the acceptance criteria. Do not send
real customer or sensitive data to a candidate during discovery.
